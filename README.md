# AI Resume Analyzer

AI Resume Analyzer is a Python and Streamlit based application that analyzes a resume against a Job Description.

## Features

- Upload Resume (PDF, DOCX, TXT)
- Enter Job Description
- Extract relevant skills
- Identify matched skills
- Identify missing skills
- Calculate Resume Match Percentage
- Calculate Resume Score
- Provide improvement suggestions
- Download Analysis Report

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- PyPDF
- python-docx

## How It Works

1. Upload your resume.
2. Enter the Job Description.
3. The application extracts relevant skills.
4. Resume skills are compared with Job Description skills.
5. Resume Match Percentage and Resume Score are displayed.
6. Matched and missing skills are shown.
7. An analysis report can be downloaded.

## Project Objective

The goal of this project is to help job seekers understand how closely their resume matches a particular job description and identify skills they may need to improve.
